# Attendance UI Redesign — Approved Mockups

These five HTML pages are the visual reference for
[`docs/specs/2026-08-31-attendance-ui-redesign-design.md`](../../specs/2026-08-31-attendance-ui-redesign-design.md)
and the task breakdown in
[`docs/plans/active/2026-08-31-attendance-ui-redesign.md`](../../plans/active/2026-08-31-attendance-ui-redesign.md).

They are exploration output from the approved brainstorm, copied out of the
gitignored `.brainstorm/` directory so that every worktree and every agent has
the same visual authority. Open them in a browser.

| File | Covers |
| --- | --- |
| `dashboard-foundation.html` | Visual foundation, unified dashboard, sidebar and bottom navigation |
| `calendar-detail-interaction.html` | Month grid, day states, and the three day-detail options — **option A was approved** |
| `calendar-day-editor.html` | Calendar to day-editor transition and the editor layout |
| `management-wizards.html` | Managed files hub, members, and the shared wizard shell |
| `login-states-photo-responsive.html` | Login with the retained image on desktop and mobile, the system state gallery, debug disclosure, and the accessibility foundation |

## Authority

The written spec is the contract; these pages are not. **Where a mockup and the
spec disagree, the spec wins.** Several pages also present rejected options side
by side with the approved one — read the spec's §13 approval record before
copying a layout.

They are a snapshot. They are not updated as implementation proceeds; the
product document and the code become the living truth once a surface ships.
